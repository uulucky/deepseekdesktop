DeepSeek 桌面客户端 · 便携版
================================

怎么用
------
1. 把整个文件夹解压到任意位置（U 盘、桌面、D 盘都可以，路径里有中文也没问题）。
2. 双击「Run-DeepSeek.cmd」，或者直接双击「DeepSeek Desktop.exe」。
3. 第一次打开会看到进度条：软件会自己在 data 文件夹里准备运行环境并把内核装好，
   之后再打开通常几秒就进界面。

不需要安装 Node.js，不需要 npm，不需要联网打开浏览器。

权限滑动条
----------
输入框下方、推理等级右侧、发送按钮左侧有三档权限：

  Read Only        只读；需要修改文件时会请求批准
  Workspace Write  只允许在工作目录和临时目录写入（默认）
  Full Access      完全访问；不再显示批准请求，启用前会再次确认

最后一次选择会用于新对话。Full Access 不会绕过 Windows 账号权限或 UAC，
但会移除软件内核自己的沙箱，只应在信任当前任务时使用。

数据放在哪
----------
全部在这个文件夹里，不会写到 C 盘用户目录：

  data\config\     设置、模型表快照
  data\runtime\    运行组件（内核 / 必要时下载的便携版 Node）
  data\chromium\   界面缓存与登录状态（DeepSeek 账号登录就保存在这里）
  data\logs\       运行日志（按天一个文件）

想彻底删除软件：直接删掉整个文件夹即可，系统里不会留任何残余。

常见问题
--------
* Windows 提示「未知发布者」：因为程序没有购买代码签名证书。点“更多信息 → 仍要运行”。
* 杀毒软件误报：便携版是未签名程序，加入信任列表即可。
* 换电脑或 U 盘盘符变了：直接在新位置双击启动器即可，数据跟着文件夹走。
* 想放到共享目录给多人用：不建议——data 目录里保存着登录状态。
* 每次启动都要等进度条？第一次之后组件已经装好，正常只需几秒。
* 网络受限：把内核组件的 .tgz 放到本地，在 设置 → 通用 → 内核安装 / 更新包 里填路径，
  重启一次即可。
